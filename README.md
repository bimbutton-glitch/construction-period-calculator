# 🏗️ 공사기간 계산기

착공일과 준공일을 입력하면 **총 공사기간, 작업가능일, D-day, 진행률**을 계산하는 웹앱입니다.

👉 **사용하기: https://bimbutton-glitch.github.io/construction-period-calculator/**

## 기능
- 총 공사기간(역일), 작업가능일, 제외일 계산
- 토요일 / 일요일 / 공휴일 제외 선택
- 대한민국 공휴일 2025–2028 (설·추석, 대체공휴일, 선거일 포함)
- 오늘 기준 D-day, 경과일, 남은 작업가능일, 경과율
- 🔗 결과 링크 복사 — 입력값이 URL에 담겨 그대로 공유 가능

## 구성
빌드 과정 없는 단일 `index.html` 파일이며 GitHub Pages로 호스팅됩니다.
